Weekly stock-move model: test report

Generated 2026-11-16 04:40 UTC · data through 2026-11-13 · 319,491 stock-days from 31 reported stocks (trained on 102) · walk-forward test 2016-01-04 → 2026-11-13
Verdict: No reliable edge. The model is not distinguishable from a coin flip / simple baselines once you account for noise.
  • Out-of-sample accuracy 54.0% vs 56.0% for simply guessing 'up' every time (difference -2.0%, 90% range -2.9% to -1.0%).
  • ROC AUC 0.509 (0.5 = no skill; 90% range 0.494-0.524); best simple baseline AUC 0.505.
  • The 10-90% range caught the actual move 79% of the time after calibration (target 80%).
  • Backtest after costs: 47.0%/yr (Sharpe 1.37) vs 42.0%/yr (Sharpe 1.31) for just holding all the stocks. The rule beat that on risk-adjusted terms.

1. Can it call the direction?

Every number here is out-of-sample: each prediction came from a model trained only on earlier data, with a 5-day gap so the test week can't leak into training. "Accuracy" counts P(up) > 50% as an "up" call. AUC measures whether higher probabilities go with more up-weeks (0.50 = no skill, 1.0 = perfect). Brier is the probability error (lower is better; 0.25 = always saying 50%).

Experiments: can we ask an easier question?

"Will it go up?" is mostly a bet on the whole market. These experiments try easier questions: will the stock beat the average of its peers (which removes the market's move), and a one-month horizon. Each idea is developed on data before 2025-01-01 ("dev") and then graded once on data from 2025-01-01 onward (the "final exam"). An idea counts only if it passes both.

  • AUC: 0.50 = no skill (90% range in brackets).
  • Ranking IC: each day, do the stocks the model scores higher actually do better? 0 = no skill, +0.03 or more is decent; t above 2 means it's unlikely to be luck.
  • Top-5 edge/yr: yearly return of holding the model's 5 favourite stocks minus holding all of them, after trading costs.

6. Checks for bugs and leaks

  • Future-data test: Passed: 294,342 rows x 39 features are identical with data after 2025-11-17 removed.
  • Purge gap: 5 trading days between training and each test period.
  • Too-good-to-be-true alarm: accuracy > 60% or AUC > 0.65 is flagged as a probable leak. Not triggered.
  • Overlapping data: confidence ranges use a week-block bootstrap, because 30+ stocks on the same day are not independent experiments.

7. Caveats

  • The ticker list was chosen today, knowing these companies are AI winners (survivorship bias). This flatters "hold all stocks" and anything that is usually long.
  • Past earnings dates are the actual report dates; companies usually announce them only weeks in advance.
  • Short-history names (CRWV, SNDK) get predictions from patterns learned on other stocks.
  • Backtest ignores taxes, slippage on very volatile names, and the fact that you'd trade at the next open, not the close.

Not investment advice. Use the paper log (paper_log.csv) for 4-8 weeks to see live accuracy before trusting it.
